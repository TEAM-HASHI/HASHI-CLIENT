# Profile Edit Page Specification

Jira: HASHI-201

## Scope

- 인증 사용자가 마이페이지의 `수정` 버튼을 통해 `/profile/edit`로 이동합니다.
- 프로필 생성 화면과 동일한 프로필 이미지·입력 필드·검증 UI를 재사용합니다.
- 이번 범위에는 프로필 수정 API 연동을 포함하지 않습니다.

## Shared Profile Form

- 공통 프로필 UI와 폼 상태는 `features/profile`에서 관리합니다.
- 필드 순서는 닉네임, 영문 이름, 연락처, 이메일, 생년월일입니다.
- 수정 화면은 현재 조회 가능한 닉네임과 프로필 이미지를 초기값으로 사용합니다.
- 저장 버튼은 필수값이 유효하고 초기값에서 변경된 경우에만 활성화됩니다.

## Pending Integration

- 전체 프로필 조회 API를 연동하면 연락처, 이메일, 생년월일, 영문 이름을 초기값으로 전달합니다.
- 프로필 수정 API 연동 전까지 유효한 저장 요청은 `ComingSoonDialog`로 안내합니다.
- API 연동 시 저장 mutation, 필드 오류 매핑, 성공 후 query invalidation을 추가합니다.

## Verification

- 마이페이지 수정 버튼에서 `/profile/edit`로 이동합니다.
- 프로필 요약의 닉네임과 프로필 이미지가 초기값으로 표시됩니다.
- 변경 전에는 저장 버튼이 비활성화됩니다.
- 필수값 입력 및 변경 후 저장 버튼이 활성화됩니다.
- 뒤로가기 버튼은 이전 화면으로 이동합니다.
