# Page Spec: `NotFoundPage`

## 목적과 진입

- 존재하지 않는 URL(`*`) 및 기존 NotFound 사용처에서 안내를 표시한다.
- Figma `11720:96739`의 정적 404 디자인을 기준으로 한다.
- HASHI-258 사용자 확정(2026-11-23): 천막은 정적 SVG로 반영하고 휘날리는 모션은 이번 범위에서 제외한다. 기획의 반복 재생 요구는 후속 모션 작업으로 남긴다.

## 화면

- 기존 앱 레이아웃과 하단 내비게이션을 유지하며 본문 영역에서 안내 묶음을 수평·수직 중앙 정렬한다.
- 기존 28px 아래 이동 보정을 제거한다.
- Figma의 첫 번째 천막 상태 원본 SVG를 200×150px로 표시한다. SVG 내부 여백을 유지하고 별도 이미지 하단 간격을 더하지 않는다.
- 안내는 `요청하신 페이지가 사라졌거나,` / `잘못된 경로로 이동했을 수 있어요.` 두 줄이며 기존 Long Body 1·Primary 200 토큰을 사용한다.
- 안내와 버튼 사이 간격은 25px이다.
- 기존 HDS Button을 재사용하며 버튼은 185×42px, 배경은 Cool Gray 900이다.
- `홈으로 돌아가기`를 누르면 기존 `ROUTES.home`으로 이동한다. 신규 API·라우트·애니메이션은 추가하지 않는다.

## 검증

- 기존 NotFoundPage 테스트로 안내와 홈 이동을 검증한다.
- 320px·393px 실제 브라우저에서 정적 그래픽·간격·넘침을 확인한다. CSS 전용 테스트 파일은 추가하지 않는다.
